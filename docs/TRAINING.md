
# Model Training Guide

This document will describe how to reproduce the experiments performed for the bachelor's thesis.

## Research Task

Four-class music emotion recognition from audio.

## Planned Dataset

MERGE Audio Balanced.

## Planned Models

- Support Vector Machine (SVM)
- Random Forest
- Convolutional Neural Network (CNN)
- Transfer learning model (to be selected)

## Evaluation

- Accuracy
- Macro-F1
- Precision
- Recall
- Confusion matrix

## Reproducibility

The following information will be recorded for each experiment:

- Dataset version and split
- Audio preprocessing settings
- Feature extraction settings
- Model architecture and hyperparameters
- Random seed
- Training environment
- Evaluation results

Exact training commands will be added after the first implementation.
