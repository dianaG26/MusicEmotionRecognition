
# Music Emotion Recognition

Bachelor's Thesis — Music Emotion Recognition Using Machine Learning and Deep Learning.

## Project Overview

This project investigates automatic music emotion recognition using traditional machine learning and deep learning approaches.

The goal is to classify music audio into four emotional categories based on the valence-arousal model and compare the performance of different methods.

## Planned Technologies

- librosa
- scikit-learn
